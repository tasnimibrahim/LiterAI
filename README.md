# LiterAI — AI-Powered Academic Research Assistant

LiterAI is a full-stack AI-powered academic research assistant that helps researchers find, analyze, and synthesize academic papers using multiple sources (arXiv, PubMed, Semantic Scholar, and more).

## Features

- 🔍 Multi-source academic paper search
- 🤖 AI-powered research chat with LLM integration
- 📊 Model evaluation dashboard
- 📝 Research report generation
- 🗂️ Project & chat management
- 🔐 Local authentication with JWT
